# Prova de Programação 1

Este repositório foi criado para armazenar o enunciado oficial da prova de Programação 1, contendo questões voltadas para lógica de programação, estruturas de repetição, condicionais, manipulação de dados e resolução de problemas utilizando Python.

O material representa uma avaliação prática desenvolvida no contexto da disciplina introdutória de programação, reunindo exercícios com foco em raciocínio lógico, interpretação de problemas e implementação de algoritmos.
